## retrieve

Get a queue

### Example Usage

<!-- UsageSnippet language="python" operationID="getQueue" method="get" path="/queue/{id}" -->
```python
from moderation_api import ModerationAPI
import os


with ModerationAPI(
    secret_key=os.getenv("MODAPI_SECRET_KEY", ""),
) as ma_client:

    res = ma_client.queue.retrieve(id="<id>")

    # Handle response
    print(res)

```

## get_stats

Get detailed statistics about a moderation queue including review times, action counts, and trends

### Example Usage

<!-- UsageSnippet language="python" operationID="getQueueStats" method="get" path="/queue/{id}/stats" -->
```python
from moderation_api import ModerationAPI
import os


with ModerationAPI(
    secret_key=os.getenv("MODAPI_SECRET_KEY", ""),
) as ma_client:

    res = ma_client.queue.get_stats(id="<id>", within_days=30)

    # Handle response
    print(res)

```

### Example Usage

<!-- UsageSnippet language="python" operationID="getAccount" method="get" path="/account" -->
```python
from moderation_api import ModerationAPI
import os


with ModerationAPI(
    secret_key=os.getenv("MODAPI_SECRET_KEY", ""),
) as ma_client:

    res = ma_client.account.retrieve()

    # Handle response
    print(res)

```

# Content

## Overview

### Available Operations

* [submit](#submit) - Submit content

## submit

Submit content

### Example Usage

<!-- UsageSnippet language="python" operationID="submitContent" method="post" path="/moderate" -->
```python
from moderation_api import ModerationAPI
import os


with ModerationAPI(
    secret_key=os.getenv("MODAPI_SECRET_KEY", ""),
) as ma_client:

    res = ma_client.content.submit(content={
        "type": "text",
        "text": "Hey, check out my profile for a deal!",
    }, content_id="message-48213", author_id="user-1092", conversation_id="room-general", metadata={
        "platform": "ios",
    })

    # Handle response
    print(res)

```
